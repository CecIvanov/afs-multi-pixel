# No prior Shopify consent sought under API Terms §2.3.19

Shopify API Terms §2.3.19 requires prior written consent for apps whose primary purpose is passing Merchant Data to a third party. We don't seek it: the merchant supplies their own Meta pixel and token per Market, so the app sends data only where the merchant directs, consent-gated and with personal data hashed. Many listed Conversions API apps work the same way. If App Review raises §2.3.19, we deal with it then. This is a deliberate risk, not an oversight.

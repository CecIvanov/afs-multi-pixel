## Question

Graduated from the map's fog: help center, setup guide and verification checklist for a standalone, English-only app.

## Answer

Agreed with the user, 2026-10-01. English help pages on `adfeedstudio.com`:
- A setup guide (app embed, pixel + token per Market, cookie consent).
- Verifying events in Events Manager (browser + server, deduplicated).
- An FAQ, including that sharing a pixel with the Official Meta App double counts.

Support is by email. The app links to the help pages and support from the setup strip. Writing the content itself is out of scope for this map.
